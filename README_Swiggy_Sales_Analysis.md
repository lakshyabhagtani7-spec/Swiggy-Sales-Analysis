# Swiggy Sales Analysis Dashboard (Excel)

## Project Overview

This project analyzes Swiggy food listing and pricing data using
Microsoft Excel. The workbook contains a raw dataset and supporting
analysis tables that explore sales value, restaurant and dish
performance, ratings, food categories, and geographic trends.

The objective is to turn a large dataset into useful business insights
through Excel formulas, PivotTables, and an interactive dashboard.

## Dataset

-   **Records:** 197,430
-   **Columns:** 14
-   **Geographic fields:** State, City, and Location
-   **Business fields:** Restaurant Name, Category, Dish Name, and Food
    Type
-   **Date fields:** Order Date, Day, Quarter, and Week
-   **Measures:** Price (INR), Rating, and Rating Count

## Tools & Skills

-   Microsoft Excel
-   PivotTables and PivotCharts
-   Excel formulas and aggregations
-   Data analysis and summarization
-   Dashboard reporting and business insight generation

## Analysis Performed

The workbook includes analysis of: - Overall price value and average
rating - Monthly and daily trends - Quarterly performance - State-wise
performance - Top five cities by price value - Veg and non-veg category
comparison - Restaurant, location, category, and dish-level data
exploration

## Key Figures in the Workbook

-   **Total price value:** ₹53,012,505.77
-   **Average rating:** 4.34
-   **Dish records counted:** 197,430
-   **Veg price value:** approximately ₹34.56 million
-   **Non-veg price value:** approximately ₹18.45 million

*Note: These are the aggregated figures displayed in the workbook.
"Price value" is the sum of the Price (INR) field; it should not be
interpreted as confirmed Swiggy revenue or completed order sales unless
the dataset's business definition confirms that.*

## Files

-   `Swiggy Raw Data Excel.xlsx` --- Excel workbook containing the
    source data and analysis.

## How to Use

1.  Download the Excel workbook from this repository.
2.  Open it in Microsoft Excel.
3.  Go to the **Swiggy Data** sheet to explore the dataset.
4.  Review the analysis tables and dashboard elements to understand the
    findings.
5.  Use available PivotTable filters or slicers, where supported, to
    explore different categories and locations.

## Project Objective

The project demonstrates practical Excel skills for organizing,
analyzing, and presenting food-platform data. It is intended as a
portfolio project showcasing data analysis and dashboard reporting.
